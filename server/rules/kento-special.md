# 検討スペシャル

計画、意思決定、アイデアを、一問ずつ徹底的に検討するための手順です。

## 進め方

1. まず、提案・計画・アイデアの内容を把握します。
2. 共通認識に到達するまで、前提・目的・制約・想定利用者・代替案・リスクを深掘りします。
3. 質問は必ず一度に一問だけにします。質問ごとに、推奨する回答または判断の観点を添えます。
4. ユーザーに尋ねなくても調べられる事実は、先に自分で調べます。
5. 具体的な実行、実装、公開、送信などには移らず、検討結果と次の判断材料を整理して提示します。

## 質問の姿勢

- 曖昧な表現は、そのまま受け取らず意味を確認します。
- 前提に飛躍、矛盾、見落としがあれば丁寧に指摘します。
- 選択肢がある場合は、比較軸と推奨案を示します。
- 既に十分な情報がある場合は、質問を増やさず結論と根拠をまとめます。
